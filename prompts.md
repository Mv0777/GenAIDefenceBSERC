# GenAI Internship Week 2 — Ordered Build Prompts (`prompts.md`)

## Section A: Web Tools
### Project 2: Form Photo Fixer (`section_a_web_tools/project2_form_photo_fixer/index.html`)
1. "Build an offline browser tool called Form Photo Fixer with presets for GATE/UPSC (350x450 px, max 50 KB), SSC/IBPS (200x230 px, max 40 KB), Standard Signature (280x100 px, max 20 KB), and custom dimensions/KB limits."
2. "Add an HTML5 canvas preview with a dashed oval face alignment guide, a zoom slider, iterative JPEG quality step-down compression until the output is strictly under the target KB limit, and a one-click download button."

### Project 3: Resume Builder (`section_a_web_tools/project3_resume_builder/index.html`)
1. "Create an offline A4 Resume Builder with a split-screen form and live A4 sheet preview. Include 3 distinct templates (Classic Academic, Modern Tech Blue, Executive Serif), up/down buttons to reorder sections, JSON export/import to save and restore user data, and CSS `@media print` rules for clean selectable PDF export."

## Section B: Phone Apps & Games
### Project 7: Bill Book (`section_b_phone_apps_games/project7_bill_book/index.html`)
1. "Build a mobile-first offline shop billing web app with item entry, discount and GST percentage calculation, deterministic UPI payment QR code generation on canvas, WhatsApp share summary alert, and `localStorage` persistence for bill history and daily total sales."

### Project 8: Auto Rally (`section_b_phone_apps_games/project8_auto_rally/index.html`)
1. "Create a mobile-friendly 3-lap auto-rickshaw lane-racing HTML5 canvas game with both keyboard arrow controls and large on-screen touch buttons, collectible coins, obstacle cones, a live lap timer, and persistent best-time tracking via `localStorage`."

## Section C: Chrome Extensions
### Project 10: Job Clipper (`section_c_chrome_extensions/project10_job_clipper/`)
1. "Build a Manifest V3 Chrome Extension called Job Clipper that auto-fills the current tab's title into a role input, lets the user edit company, deadline, and Kanban stage (Saved, Applied, Interview, Result), persists entries locally, and exports all saved applications to a CSV file."

### Project 12: Chat Saver (`section_c_chrome_extensions/project12_chat_saver/`)
1. "Build a Manifest V3 Chrome Extension called Chat Saver that extracts conversation blocks from the active AI chat page and downloads a formatted Markdown (`.md`) file named after the page title, plus a one-click Print/Save as PDF button."

## Section D: Video, Skills & Design
### Project 16: Your Own Skill (`section_d_video_skills_design/project16_your_own_skill/SKILL.md`)
1. "Create a reusable agent skill named `one-page-revision` (`SKILL.md`) that converts raw chapter notes into a structured one-page exam revision sheet with core definitions, LaTeX formulas, a trade-off table, common pitfalls, and 3 viva questions."

### Project 17: Same Page, New Design (`section_d_video_skills_design/project17_same_page_new_design/`)
1. "Create a plain unstyled HTML landing page (`before.html`) for TECHNOVA 2026, then redesign it (`after.html`) using the exact same text with modern dark-mode gradients, glassmorphism cards, responsive CSS grid layout, and a pill-shaped CTA button."
