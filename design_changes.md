# Design Changes Summary (Project 17: Same Page, New Design)
1. **Visual Hierarchy & Typography:** Replaced default unstyled HTML headings with fluid `clamp()` sizing, gradient display typography, and high-contrast slate/indigo surfaces so the event title and CTA stand out immediately.
2. **Card-Based Track Grid:** Converted the plain bulleted `<ul>` list into a responsive CSS Grid of elevated glassmorphic cards that adapt cleanly on mobile screens.
3. **Interactive Call-to-Action Pill:** Styled the plain browser button into a high-contrast gradient pill CTA with soft glow elevation while keeping every single word identical between `before.html` and `after.html`.
